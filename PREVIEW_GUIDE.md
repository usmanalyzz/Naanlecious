# 👀 Visual Preview Guide - Naanlecious Landing Page

## 🎨 What Your Landing Page Looks Like

This guide describes the visual appearance and user experience of each section.

---

## 📱 Full Page Flow

When visitors land on your site, they'll experience:

1. **Navbar** (always visible at top)
2. **Hero Section** (first impression)
3. **Menu Preview** (food showcase)
4. **About Section** (brand story)
5. **Testimonials** (social proof)
6. **Contact Section** (get in touch)
7. **Footer** (final information)

Total page length: ~7000px (scrollable)

## 🎭 Interactive Elements

### Hover Effects

- **Buttons**: Scale up + shadow increase
- **Menu cards**: Lift up (translate -10px)
- **Links**: Underline animation + color change
- **Social icons**: Rotate + scale

### Animations

- **On Load**: Fade in from top/bottom/sides
- **On Scroll**: Fade in when section enters viewport
- **Continuous**: Floating background circles, pulsing heart
- **Staggered**: Menu items appear one by one

### Mobile Features

- **Hamburger menu**: Smooth slide-down animation
- **Touch-friendly**: All buttons have proper tap targets
- **Swipe-friendly**: Smooth scrolling

1. **Colors**: Edit `tailwind.config.js`
2. **Images**: Replace Unsplash URLs
3. **Text**: Edit component files directly
4. **Layout**: Adjust Tailwind grid classes
5. **Animations**: Modify Framer Motion props
